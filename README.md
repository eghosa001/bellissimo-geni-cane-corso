# Bellissimo Geni Cane Corso

Premium responsive kennel website for Bellissimo Geni Cane Corso, Nigeria.

## Included

- Luxury editorial-style responsive homepage
- Puppy cards with NGN pricing
- Breed standards and responsible-ownership section
- Enquiry form that prepares a WhatsApp message
- Mobile-first responsive layout
- No framework or build step required
- GitHub Pages compatible

## Run locally

Open `index.html` in a browser. For a local server, use any static server such as VS Code Live Server.

## Before launch

1. Replace the demo WhatsApp number in `app.js`.
2. Replace the sample puppy names, prices and availability with real kennel data.
3. Replace the visual placeholders with licensed kennel/puppy photography.
4. Add the kennel's real location, phone, social links and operating details.
5. Verify every puppy health/pedigree claim before publishing.
6. Configure GitHub Pages or another static host.

## Deployment

GitHub Pages can host this project directly because it is a static HTML/CSS/JS site. The repository is intentionally dependency-free so deployment remains simple and reliable.
